PROYECTO RED NEURONAL - SIMULACIÓN DE IMPULSOS NERVIOSOS

DESCRIPCIÓN:
Aplicación que simula una red neuronal biológica usando grafos dirigidos. 
Permite cargar redes neuronales desde CSV, calcular rutas de transmisión 
con Dijkstra, y buscar componentes conexos con DFS y BFS.
